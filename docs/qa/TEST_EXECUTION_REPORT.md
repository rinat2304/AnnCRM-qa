## 7. Общий результат

Baseline-тестирование завершено.

Основной функционал приложения проверен.

Обнаружен дефект, позволяющий создавать клиентов с полностью идентичными данными.

Дефект затрагивает как API, так и пользовательский интерфейс.

Дефект зарегистрирован отдельно в `BUG_REPORTS.md`.

Исправление дефекта в рамках текущего тестового прогона не выполнялось.

После исправления необходимо выполнить:

1. Retest связанных сценариев.
2. Regression testing функциональности Clients.
3. Проверку создания клиентов через API и UI.
4. Проверку невозможности обхода ограничения через прямой API-запрос.
